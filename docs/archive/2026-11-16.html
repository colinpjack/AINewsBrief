A suspected Russian-speaking operator used an AI agent to turn security patches into working exploits with no human in the loop – a first such occurrence, according to the Google Threat Intelligence Group (GTIG) – before ultimately stealing data from victim organizations. Google documented this attack in its fourth-quarter 2026 AI threat tracker, and said it marks a significant advance in how attackers use LLMs for fully autonomous vulnerability discovery and exploitation compared to Q3. In this case, the threat hunters found an exposed staging server hosting a multi-agent vulnerability research and weaponization framework that integrates with multiple frontier and local models.

The framework, called exploit_agent, used Russian-language tooling, and was configured to conduct continuous differential analysis of “popular web application software,” according to the report . This includes comparing code before and after security updates, identifying potential vulnerabilities, developing exploits, and then automatically executing them without any human involvement. The server also contained data stolen from victim organizations, and “multiple” post-compromise scripts that allowed attackers to perform nefarious activities including internal reconnaissance, brute-forcing, installing webshells, and removing other attackers’ webshells.

“Victim telemetry on the server suggests the operator was specifically interested in targeting French websites associated with the media and entertainment industries, as well as the education sector,” according to the report. The report also documents other instances of attackers moving beyond manual LLM prompting during cyberattacks and instead deploying autonomous, multi-agent offensive security frameworks to carry out multi-stage intrusions.
